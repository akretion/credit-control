Allianz Trade provider for ``partner_credit_rating``: company
identification with the Company Search API and grades with the Grade
Check API.

Grades 01-03 are low risk, 04-06 medium, 07 high, 08-10 critical.

Configuration
=============

In *Settings > General Settings > Contacts > Credit Rating*, select
Allianz Trade then fill the API key, Business Unit Code, Policy ID and
base URLs.

Companies are searched by Company ID (SIREN for France, from SIRET or
VAT) then by tax ID. Extend ``REGISTRY_TYPES`` for other countries.
